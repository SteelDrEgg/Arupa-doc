本页列出了由内核和核心服务暴露的 KV 惯例。每个条目定义了某个键代表的信息，以及当前由哪个组件负责发布它。关于 KV 操作和存储行为，请参阅 [KV 存储指南](./isc-kv)。

## 内核的服务记录

内核会在只读的 `sys` 命名空间中发布服务元数据。这些记录让其他组件能够区分一个可用的服务包与一个已在内核中注册的服务实例。

| 键模式 | 定义者 | 含义 |
| --- | --- | --- |
| `sys/service/catalog/<service-name>` | 内核 | 扫描期间发现的某个服务包的元数据。 |
| `sys/service/<instance-id>` | 内核 | 某个已加载服务实例的元数据，以及它注册的路由和传输。 |

目录（catalog）记录描述的是包元数据，包括服务身份、版本、运行时类型、契约版本、命令、包路径和清单元数据，它并不表示该服务正在运行。

运行实例记录描述的是已注册的实例及其路由和传输。当该实例停止或被卸载时，内核会移除这条记录。一个处于 degraded 状态的实例仍然可以有对应的记录；该记录反映的是已成功注册的路由和传输。

## 已发布的应用元数据

服务会在从其所属服务名称派生出的命名空间下发布元数据。以下键是目前的惯例，用于其他服务或前端代码可能需要发现的资源。

| 键 | 定义者 | 值的含义 |
| --- | --- | --- |
| `web-assets/urls` | `web-assets` 服务 | 一个 JSON 对象，将每个已发布的 Web 资源名称映射到其公开 URL。 |
| `web-assets/style` | `web-assets` 服务 | 共享样式表的公开 URL。 |
| `web-assets/color-scheme` | `web-assets` 服务 | 配色方案样式表的公开 URL。 |
| `web-assets/icon` | `web-assets` 服务 | 共享图标的公开 URL 前缀。 |
| `web-assets/culori` | `web-assets` 服务 | Culori JavaScript 资源的公开 URL。 |
| `web-sdk/urls` | `web-sdk` 服务 | 一个 JSON 对象，将每个 SDK 资源名称映射到其公开 URL。 |
| `web-sdk/sdk` | `web-sdk` 服务 | Web SDK 脚本的公开 URL。 |
| `web-sdk/languages` | `web-sdk` 服务 | SDK 语言元数据的公开 URL。 |

聚合的 `urls` 键与其对应的各个独立键描述的是同一组资源。需要发现全部资源时使用聚合键；只需要某个特定资源时使用对应的独立键。
