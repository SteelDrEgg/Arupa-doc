title: "简介"
description: "了解 Arupa 内核及其如何托管服务。"
---

Arupa 内核是 Arupa 的核心宿主进程。它提供服务赖以构建的共享服务器运行时环境，因此每个服务都可以专注于自身的功能，而无需自行实现服务器、身份验证或服务间通信。

内核负责：

- 处理 HTTP 请求和 Socket.IO 连接；
- 发现、加载、启动和停止服务，以及重新加载配置；
- 将服务声明的传输（transport）和路由（route）——包括 HTTP 路由、静态文件、Socket.IO 命名空间以及代理的上游地址——连接到服务器；
- 提供共享主机 API，例如键值存储、日志记录、事件发射和服务消息；以及
- 对请求进行身份验证，并强制执行已配置的主机、服务和路由访问策略。

服务以 `wasm` 模块、独立的 `grpc` 进程运行，或者对于纯打包内容，以完全不含代码的 `static` 服务运行。`wasm` 和 `grpc` 服务在启动时会与内核完成一次身份握手，随后声明它们提供的传输和路由。内核会将匹配的请求和事件分派给所属服务，同时将主机级别的身份和访问检查集中在一处。

要运行 Arupa，首先需要安装内核，然后选择适合您环境的安装方法。
